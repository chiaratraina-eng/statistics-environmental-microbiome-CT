# statistics-environmental-microbiome-CT

Statistical analysis and figure generation code for bacterial and fungal metabarcoding data.

This repository accompanies the manuscript: *Microbial continuity across an olive farm-to-food continuum reveals stable reservoirs, ecological filtering and microbiome transmission, Environmental Microbiome, currently with editor*.

## Overview

Raw 16S rRNA gene and ITS sequencing reads (2022 and 2023) were processed with the MetaFlux workflow (https://github.com/iLivius/MetaFlux), which produced the ASV tables and read-count summaries used here. This repository contains only the downstream statistical analyses and figure generation.

Raw sequencing reads are available at the European Nucleotide Archive (ENA) under project accession PRJEB108463.

## Repository contents

- `scripts/` – Quarto document with the statistical analyses and figures of the study
- `data/` – description of the required input files (the data are not stored in this repository)

## Software requirements

- R version 4.5
- Quarto 1.9.36

## Input data

The analyses require the following files, generated by the MetaFlux workflow:

- `bac_meta_full.tsv` - sample metadata
- `bac/03.dada2_output/asv_table.txt` - bacterial ASV table
- `bac/04.stats/02.filtered_reads.txt` - bacterial read counts at each processing step
- `fun/03.dada2_output/asv_table.txt` - fungal ASV table
- `fun/04.stats/02.filtered_reads.txt` - fungal read counts at each processing step

These files are not included in this repository. They will be available at:  *to be added: Zenodo DOI / link*

## How to run

1. Download the input files and keep the folder structure described above.
2. Set the path to the input folder in the first chunk of the script (`data_dir`).
3. Render the document with Quarto: `quarto render scripts/[script name].qmd`
