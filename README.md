# statistics-environmental-microbiome-CT

Statistical analysis and figure generation code for bacterial and fungal metabarcoding data.

This repository accompanies the statistical analysis of the manuscript *Microbial continuity
across an olive farm-to-food continuum reveals stable reservoirs, ecological filtering and
microbiome transmission*, submitted to Environmental Microbiome.

## Overview

Raw 16S rRNA gene and ITS sequencing reads (2022 and 2023) were processed with the MetaFlux
workflow (https://github.com/iLivius/MetaFlux), which produced the ASV tables and read-count
summaries used here. This repository contains only the downstream statistical analyses and
figure generation, in a pinned R environment (`renv`).

Raw sequencing reads are available at the European Nucleotide Archive (ENA) under project
accession PRJEB108463.

## Repository contents

| Path | Content |
|---|---|
| `domino_analysis.R` | the analysis; reproduces Figures 2–5 and Supplementary Tables 1–4. Its header maps each figure/table to a script section |
| `renv.lock`, `renv/`, `.Rprofile` | the pinned R package environment |
| `output/tables/` | reference results: `SuppTable<N>_*.csv` and `Fig*_*.csv` (the numbers quoted in the Results) |
| `output/sessionInfo.txt` | R session of the reference run |

`output/figures/` (`Fig<N><panel>_*.svg/.png`) is not tracked; the script regenerates it.

## Input data

The analyses require the following files, generated by the MetaFlux workflow:

- `bac_meta_full.tsv` - sample metadata (Area, Tree, Compartment, Replicate, Time, Year)
- `bac/03.dada2_output/asv_table.txt` - bacterial ASV table
- `bac/04.stats/02.filtered_reads.txt` - bacterial read counts at each processing step
- `fun/03.dada2_output/asv_table.txt` - fungal ASV table
- `fun/04.stats/02.filtered_reads.txt` - fungal read counts at each processing step

These files are not included in this repository. They are available at Zenodo:
[10.5281/zenodo.23190089](https://doi.org/10.5281/zenodo.23190089).

## How to run

Requires R 4.6 (tested with 4.6.1). On macOS with Homebrew R, `lme4` needs `brew install nlopt`.

```bash
git clone https://github.com/chiaratraina-eng/statistics-environmental-microbiome-CT.git
cd statistics-environmental-microbiome-CT
# download the Zenodo files into this folder, keeping the structure above
Rscript -e 'renv::restore()'   # first time only: installs the pinned packages
Rscript domino_analysis.R      # takes a few minutes; writes to output/
```

Rarefaction uses a fixed seed (`seed = 42`), so a run reproduces `output/tables/` exactly.
Check with `git status`: no table should show up as modified.

## Reproduction of the published results

- **Identical to the manuscript:** Figures 2, 3B, 3C, 4D and 5C (not rarefied).
- **Within rarefaction noise:** all other numbers and figures, typically < 1 percentage point.
  Compact-letter displays and significance calls match the supplementary tables. The original
  analysis called `rtk()` without a seed, so its rarefied results cannot be reproduced exactly.
- **Beta-diversity read cutoff = 1,000.** The original analysis code overwrote it with 500 further
  down; 1,000 reproduces the published PERMANOVA and PCoA values.
